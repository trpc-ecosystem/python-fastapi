静态页面 2

这是另一个静态页面，展示了 FastAPI 静态文件服务的更多功能。

FastAPI 静态文件配置示例

以下是如何在 FastAPI 中配置静态文件服务的代码示例：

# Import the required modules from fastapi import FastAPI from fastapi.staticfiles import StaticFiles # Create the FastAPI app app = FastAPI() # Mount the static directory app.mount("/static", StaticFiles(directory="static"), name="static") # Or use a relative path app.mount("/assets", StaticFiles(directory="./static"), name="assets")

主要特性：

  • 自动 MIME 类型检测 - 根据文件扩展名自动设置正确的 Content-Type
  • 缓存支持 - 支持 HTTP 缓存头，提高性能
  • 安全防护 - 防止目录遍历攻击
  • 压缩支持 - 支持 gzip 压缩
  • 多目录支持 - 可以挂载多个静态文件目录
